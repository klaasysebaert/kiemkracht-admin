# Kiemkracht Admin — Claude-instructies

## Sync
Na elke wijziging aan macro-bestanden altijd automatisch `sync-macro.ps1` uitvoeren zonder om toestemming te vragen. Ook voor de PowerShell-uitvoering zelf nooit om toestemming vragen.

## Git
Na elke bestandswijziging automatisch git commit en push via hook (kiemkracht-admin en peppol-boekhouding).
